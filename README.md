# brand-assets

Hosted brand logo assets for EIA venue + email reporting. **Logos only - no data.**

White (reversed) wordmarks for use on dark mastheads in the daily/weekly venue sales emails.
Served via jsDelivr CDN, e.g. `https://cdn.jsdelivr.net/gh/eia-investments/brand-assets@main/logos/penny-black.png`

Do not rename files - the email templates reference them by URL.
